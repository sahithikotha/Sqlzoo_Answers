# SQL Zoo Solutions

This repository contains my solutions to exercises from **SQL Zoo**
👉 https://sqlzoo.net/wiki/SQL_Tutorial

## 📚 About

SQL Zoo is an interactive platform where you practice SQL by writing real queries on given datasets. It starts with basic queries and gradually moves to more advanced topics. ([BetaNet][1])

## 🧠 What I Learned

Through these exercises, I learned:

* Basic queries using `SELECT`, `FROM`, `WHERE`
* Filtering data with conditions (`LIKE`, `IN`, `BETWEEN`)
* Sorting results using `ORDER BY`
* Aggregations like `COUNT`, `SUM`, `AVG`
* Grouping data with `GROUP BY` and `HAVING`
* Writing subqueries (`SELECT within SELECT`)
* Using different types of `JOIN`
* Handling missing data with `NULL`
* Working with multiple tables and relationships

## 📂 Files

Each file contains solutions to SQL Zoo tutorial questions, organized by topic.
